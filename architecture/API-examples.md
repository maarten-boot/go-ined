# API examples — go-ined

Generated by `scripts/gen-api-examples.sh` from a live `ined-server`. IDs, timestamps and `run_id` will differ on your system.
The steps run in order; each one depends on the ones before it.

```bash
ined-server -listen 127.0.0.1:8470 &
INED=http://127.0.0.1:8470
# With a token configured, add: -H "Authorization: Bearer $TOKEN"
```

### Health

```bash
curl -s $INED/api/v1/health
```

Response: `200`

```json
{
  "status": "ok",
  "version": "dev",
  "icmp_mode": "disabled",
  "db": "ok",
  "run_id": "66b162d5134535d0"
}
```

### Error: duplicate IP address

```bash
curl -s -X POST $INED/api/v1/hosts -d '{"ip":"192.168.1.10"}'
```

Response: `409`

```json
{
  "error": {
    "code": "conflict",
    "message": "IP address 192.168.1.10 already belongs to host 1"
  }
}
```

### Error: CIDR with host bits set

```bash
curl -s -X POST $INED/api/v1/groups -d '{"cidr":"10.0.0.5/24"}'
```

Response: `400`

```json
{
  "error": {
    "code": "invalid_argument",
    "message": "CIDR \"10.0.0.5/24\" has host bits set; use 10.0.0.0/24"
  }
}
```

### Error: nested network group outside its parent

```bash
curl -s -X POST $INED/api/v1/groups -d '{"cidr":"10.0.0.0/24","parent_id":1}'
```

Response: `409`

```json
{
  "error": {
    "code": "conflict",
    "message": "network group 10.0.0.0/24 is not inside its enclosing network group 192.168.1.0/24"
  }
}
```

### Error: deleting a non-empty group without children=

```bash
curl -s -X DELETE "$INED/api/v1/groups/1"
```

Response: `409`

```json
{
  "error": {
    "code": "conflict",
    "message": "group 1 is not empty; use children=reparent or children=cascade"
  }
}
```

### Delete a group and move its contents up one level

```bash
curl -s -X DELETE "$INED/api/v1/groups/2?children=reparent"
```

Response: `204`

### Delete a group with everything in it

```bash
curl -s -X DELETE "$INED/api/v1/groups/1?children=cascade"
```

Response: `204`

## inedctl

The same server through the command-line client. `INED_URL` (or `--url`) points it at the server.

### Delete a group with everything in it

```bash
inedctl group rm 3 --cascade
```

No output.

Exit code: `0`

### Add a network group

```bash
inedctl group add --cidr 10.10.0.0/24 --name lab
```


### Error from the API: exit code 1

```bash

```

```text
inedctl: not_found (HTTP 404): host 99 not found
```

Exit code: `1`

### Usage error: exit code 2

```bash
inedctl host move 5
```

```text
inedctl: host move: missing argument
Run 'inedctl -h' for usage.
```

Exit code: `2`

### Server not reachable: exit code 3

```bash
inedctl --url http://127.0.0.1:1 health
```

```text
inedctl: Get "http://127.0.0.1:1/api/v1/health": dial tcp 127.0.0.1:1: connect: connection refused
```

Exit code: `3`
