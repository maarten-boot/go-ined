| 15 | L | SPEC-712 counts: should unmonitored hosts be counted? | Count monitored hosts only, plus `n off` if there are any |
| 16 | L | SPEC-802: should `/health` need a token? Not defined | `/health` is open but returns only `{status, version}` without a token. Full details need the token |
| 17 | L | SPEC-802 says a token is "required" on non-loopback, but doesn't say what happens without one. TC-801 assumes the server refuses to start | Make it explicit: the server refuses to start |
| 18 | L | Reverse-DNS load for 5,000 hosts every hour has no concurrency limit | SPEC-401: add `dns_concurrency` (default 20) |
