## 2. Code → Spec (bugs found in the code)

| # | Sev | Finding | Evidence | Proposed fix |
|---|-----|---------|----------|--------------|
| C1 | **H** | **Two `ined-server` processes can use the same database at once.** Each keeps its own in-memory model and assigns IDs on its own, and `INSERT … ON CONFLICT(id) DO UPDATE` then **silently overwrites the other process's rows** | Probe: a second `store.Open` on the same file succeeds | Take an exclusive lock at start (lock file `ined.db.lock` with `flock`, or SQLite `locking_mode=EXCLUSIVE`). A second server refuses to start with "database in use". New **SPEC-604** and TC-604 |
| C2 | M | **IDs are reused after a restart.** When the highest id is deleted, `max(id)+1` hands it out again. A GUI, a script or an event replay could mistake the new item for the deleted one | Probe: deleted host 2; after a restart the next new host got id 2 | Persist the next ids in a `meta` table (migration 2), written in the same transaction. New **SPEC-116** "ids are never reused" and TC-113 |
| C3 | M | **A database path containing `?`, `#` or `%` opens the wrong file.** The path is pasted into a `file:` URI without escaping | Probe: `a?b.db` and `a#b.db` created a file named `a`; `a%20b.db` created `a b.db` | Build the DSN with `url.URL` so the path is escaped. Extend TC-603 |
| C4 | L | **Inconsistent data at load is accepted silently.** A row whose `parent_id` points to a missing group stays attached to that missing id | Probe: a host with `parent_id = 42` loaded and is served with `parent_id: 42` | At load: move orphans to the root with a warning in the log; refuse to start on a cycle. New **SPEC-605** and TC-605 |
| C5 | L | `-version` prints to stderr; the usual convention is stdout | `cmd/ined-server/main.go` | Print to stdout |
| C6 | L | `http.Server` has no `IdleTimeout`. Read and write timeouts are deliberately unset because of SSE (M2) | `main.go` | `IdleTimeout: 120s` |
| C7 | L | The nesting error repeats the CIDR when the name is the CIDR: `"10.0.0.0/24" (10.0.0.0/24)` | API-examples.md | Show the CIDR only once when name == CIDR |

## 8. Resolution (2026-11-10)

The user approved **all** fixes, a README and the MIT licence. The code went on branch `fix/crosscheck-02`; the docs are in Spec v0.7, Plan v0.7 and Tests.md.

- **C1:** SQLite `locking_mode=EXCLUSIVE`, with `BEGIN EXCLUSIVE` at open and `busy_timeout(0)`. A second opener gets `ErrLocked` at once. Added **SPEC-604** and TC-604.
- **C2:** migration 2 adds a `meta` table with `next_host_id` and `next_group_id`, seeded from `MAX(id)`. They are written in the same transaction as each create. Added **SPEC-116** and TC-113.
- **C3:** the DSN is built with `url.URL`, from an absolute path. TC-603 now covers `?`, `#`, `%`, spaces, non-ASCII names and relative paths.
- **C4:** orphans are moved to the root and the repair is saved, with a warning logged once. A cycle stops the startup. Added **SPEC-605** and TC-605.
- **C5:** `-version` prints to stdout. **C6:** `IdleTimeout` is 120 s. **C7:** a group named after its CIDR appears once in the message.
- **S1–S3:** added to Spec v0.7 (SPEC-107, SPEC-501, the SPEC-805 table).
- **P1:** the Plan lists `-version` for M4 and M5. **P2:** TC-603 end to end (`TestDefaultDBPath`).
- **Extras:** `README.md`, `LICENSE` (MIT), `Makefile`, and `scripts/gen-api-examples.sh`. `API-examples.md` was regenerated; the only difference apart from timestamps is the C7 message.

Test run after the fixes: `make all` passes (gofmt, vet, `go test -race`, build).
