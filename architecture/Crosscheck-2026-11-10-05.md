| S3 | — | **`inedctl health` exits 0 even when the server reports `degraded`.** That matches SPEC-903 (the API answered), but a script can't easily check the server's health | **Needs the user's decision:** <br>(a) keep exit 0 and document it; scripts use `--json` (recommended, because it keeps exit 1 meaning "the API returned an error"); <br>(b) exit 1 when the status is `degraded` |
