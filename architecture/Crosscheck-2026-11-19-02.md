## 1. Code → Spec

| # | Sev | Finding | Proposed fix |
|---|-----|---------|--------------|
| C1 | M | **A new list on a big group forces a resync on every client.** The L3 fix sends one `host.updated` per host below the group, at once. A client's event buffer holds 256 (`events.SubBuffer`); a client that reads slower than the burst is dropped and told to resync, so every GUI reloads everything. The reviewer's probe: 3,000 hosts and a reader at 30 µs per event got 258 events, then a resync. It also sends events for hosts whose list didn't change (their own, or a subgroup's). | Send no `host.updated` for this. The GUI's details pane reloads the host it shows when a `group.updated` or `group.moved` concerns a group above it, which also covers a group moved elsewhere (L4). |
| C2 | M | **The GUI stops following a check on any error of its refresh.** `refreshSNMPCheck` treats a timeout, a 5xx or a network blip like "the job is gone": Cancel disappears and the status says "cancelled" while the job runs on, and the user can't cancel it from the GUI. The reviewer's probe: a failing transport unfollowed the job. | Stop following only on 404; on other errors keep following, so the next event or refresh settles it. |
| C3 | M | **Cancel during a save hides a failure.** "Cancel" closes the dialog while the PATCH is under way; if it then fails, the reason goes to the hidden dialog only. Save and Inherit stay enabled while saving, so a double click sends twice. Read, not run. | While saving, disable Save, Inherit and Add; a failure on a closed dialog goes to the status bar. |
| L1 | L | An older event can replace a newer one in the GUI's early-event store (progress events are sent outside the job's lock), showing lower progress for a moment. | Keep the event with more hosts checked, or the finished one. |
| L2 | L | The store's cap of 50 clears it all, also the event of a job this GUI just started (only with 51 other clients' jobs at once). | Drop the oldest instead. |
| L3 | L | Trimming in `inedctl` and the dialog makes a community with a space at its ends impossible to set there (the API takes it). | Trim only in `inedctl`'s comma list, and say in SPEC-315 that the dialog and stdin keep what is typed except empty lines. |
| L4 | L | A group moved elsewhere changes its hosts' origin without an event. | With C1. |
| L5 | L | A host plus an empty group selected: "Check SNMP now (1 host)", and the one-host items (the direct check, "SNMP communities…") are gone. | When a mixed selection holds one host, also show its one-host items. |
